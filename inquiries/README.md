# 论文内容讨论记录

`inquiries/` 只保存用户实际提出的、针对具体论文内容的问询与讨论，包括研究问题、数据来源、方法、实验、证据、结论、局限和论文间比较。

AI 自动生成的候选清单、待下载或待补正文清单、可能值得讨论的问题，以及用户没有实际提出的问询，均不进入本目录。每周任务运行日志、搜索关键词与过程、网站或数据结构改造、实体名称审计、发布部署记录和通用工作流讨论同样不进入。相关工作状态应分别保存在周报、watchlist、README、受控数据文件或自动化记忆中。

## 统一格式

新记录从 [`templates/inquiry.md`](../templates/inquiry.md) 复制。每个文件使用以下结构；同一天讨论多篇论文时，为每篇重复一个二级标题区块。

```markdown
# 论文内容讨论记录｜YYYY-MM-DD

- **记录类型**：完整讨论 / 待正文核验
- **记录状态**：已完成 / 待补充
- **记录来源**：用户对话

## Paper Title

- **关联论文 ID**：索引 ID；未入库时写“未入库”
- **可靠来源**：会议官方页面、DOI、作者公开原文或 arXiv

### 原始问题

### 已核验事实

### 分析与结论

### 局限与未决问题

### 后续处理
```

只有用户实际提出论文问题后才创建记录；不得为了完整性由 AI 自动补造问题。`原始问题` 应忠实保留或概括用户的问题，事实与分析判断必须分开。只有题目、摘要或元数据时，不补写方法、实验和结论；“为何接收”等判断必须明确标为分析，不冒充审稿意见。
