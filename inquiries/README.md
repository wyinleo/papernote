# 论文内容讨论记录

`inquiries/` 只保存针对具体论文内容的问询与讨论，包括研究问题、数据来源、方法、实验、证据、结论、局限、论文间比较，以及因缺少正文而无法完成的内容核验。

以下内容不进入本目录：每周任务运行日志、搜索关键词与过程、网站或数据结构改造、实体名称审计、发布部署记录，以及不对应具体论文的通用工作流讨论。这些信息应分别保存在周报、README、受控数据文件或自动化记忆中。

## 统一格式

新记录从 [`templates/inquiry.md`](../templates/inquiry.md) 复制。每个文件使用以下结构；同一天讨论多篇论文时，为每篇重复一个二级标题区块。

```markdown
# 论文内容讨论记录｜YYYY-MM-DD

- **记录类型**：完整讨论 / 待正文核验
- **记录状态**：已完成 / 待补充

## Paper Title

- **关联论文 ID**：索引 ID；未入库时写“未入库”
- **可靠来源**：会议官方页面、DOI、作者公开原文或 arXiv

### 原始问题

### 已核验事实

### 分析与结论

### 局限与未决问题

### 后续处理
```

事实与分析判断必须分开。只有题目、摘要或元数据时，不补写方法、实验和结论；“为何接收”等判断必须明确标为分析，不冒充审稿意见。
